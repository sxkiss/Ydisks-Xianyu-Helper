## 问题与修复

| 问题 | 触发及影响 | 修复与回归 |
| --- | --- | --- |
| 人工补发租约过期后继续发送 | 原执行超过五分钟，恢复器隔离后新补发领取，旧执行仍可能继续发货 | 普通动作和补发统一使用执行租约守卫：每分钟续租，每次消息、取卡、API 卡密调用及确认发货前复核；失权取消并等待心跳退出。模拟旧代次恢复和发送中代次变化，断言旧执行不能继续发送或确认发货。 |
| 恢复扫描覆盖续租后的状态 | 扫描后执行者续租，旧快照仍将任务改成待核对 | 按运行代次、状态、动作游标、占用和租约快照原子隔离；旧快照不改状态、不重复通知。三方言验证。 |
| 删除会话后分页无法继续 | 全部加载后删除会话，本地首页重载，但独立分页标记仍为 false | UI 和分页入口统一派生于平台/本地分页状态，消除冗余 state；回归删除后重新追加。 |
| 首页重载与追加分页交错 | 旧追加请求在首页刷新后到达，或刷新期间又启动追加 | 首页重载中止旧分页并推进代次；重载期间阻止追加。延迟响应测试验证隔离。 |
| 旧删除请求清除新会话删除状态 | 旧请求等待本地重载期间切换账号并再次删除 | 每个异步等待返回后复核删除代次；成功、失败两种晚到分支均有回归。 |
| 发送商品时切换会话遗留忙碌状态 | 商品发送尚未完成时切换账号/会话，旧回调被隔离但发送标记未清理 | 依赖变化时重置发送标记并取消旧请求；验证晚到成功不污染新会话，新会话可以发送。 |
| 成功省略 cardList 被误判或推算虚假数量 | 空账号返回 SUCCESS，省略数组但携带分页/数量元数据 | 遵守 AGENTS.md 的协议事实，按空列表处理；不从此类元数据推算商品数。覆盖 pageCount=1、pageCount=2、totalCount 非零等组合。显式数组类型错误和有数组时的完整性检查保留。 |
| MySQL 三方言回归误报 | 同一 UTC 时刻在驱动中表现为空格时间与 RFC3339 两种格式 | 测试解析后精确比较时刻；保留已有空值、默认创建时间的断言。无需改变订单生产代码或数据库 schema。 |
