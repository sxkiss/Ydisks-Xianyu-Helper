# 发货模板使用手册（中文）

[English](Delivery-Templates) | 中文

## 创建模板

1. 进入“发货模板”，点击“新建发货模板”。
2. 填写模板名称，确认是否“启用模板”。
3. 输入一条或多条消息；消息会按页面顺序分别发送。
4. 需要多条消息时点击“添加消息”，不需要的消息可以删除，但模板至少保留一条。
5. 点击“保存模板”。

## 可用变量

模板消息中可以直接使用以下变量：

- `{{order_id}}`：订单号
- `{{item_id}}`：商品 ID
- `{{item_title}}`：商品标题
- `{{buyer_id}}`：买家 ID
- `{{buyer_nick}}`：买家昵称
- `{{card_name}}`：规则绑定的卡密库存名称
- `{{cards.<变量名>}}`：规则绑定的卡密内容，例如 `{{cards.main}}`
- `{{custom.<变量名>}}`：自动化规则中填写的自定义文字

变量名不要包含空格或中文，也不要遗漏大括号。保存时系统会校验变量拼写。

## 在自动化规则中使用

1. 保存模板后进入“自动化规则”。
2. 在“付款后自动发货”或“评价后发送赠品”规则中选择“发货模板”。
3. 为模板中使用的每个 `cards` 变量绑定卡密库存。
4. 为模板中使用的每个 `custom` 变量填写对应文字。
5. 保存并启用规则，用测试订单确认消息顺序和变量替换结果。

发货模板只用于付款后自动发货和评价后发送赠品，不用于拍下改价或求评价。仍被规则引用的模板不能删除；需要删除时先在相关规则中换成其他发货方式或模板。
